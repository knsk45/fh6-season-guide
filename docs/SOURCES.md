# Источники

## Приоритет

1. **Официальные:** [Forza Festival Playlist](https://forza.net/fh6playlists), [Forza News](https://forza.net/news), [Forza Support](https://support.forza.net/).
2. **Структурированные сводки:** официальный форум Forza и еженедельные Information Thread в r/forza.
3. **Практические решения:** свежие Breakdown/Guide/Tunes-посты в r/ForzaHorizon, r/ForzaHorizon6 и r/FH6.
4. **Дополнительная проверка:** PC Gamer, Windows Central и видео, опубликованные после текущего сброса.

## Что считать доказательством

| Данные | Минимальная проверка |
|---|---|
| Даты, награды, ограничения | официальный источник или официальная графика |
| Сундук/коллекционные предметы | карта/скриншот либо два независимых описания |
| Тюнинг | текущий пост автора с машиной, классом и 9-значным кодом |
| «Самый быстрый» маршрут | сумма очков сходится; нет обязательных ежедневок будущих дней |
| Баг | несколько сообщений либо Known Issues/Release Notes |

## Маркировка

- `Подтверждено` — официальный источник или независимое совпадение.
- `Сообщество` — практический совет/тюнинг без личного теста в этом проекте.
- `Предварительно` — единственный свежий источник.
- `Не подтверждено` — решение не найдено или конфликтует.

Никогда не переносить код тюнинга из другой недели только потому, что совпадает класс автомобиля: физика, погода и список допустимых машин могут отличаться.
