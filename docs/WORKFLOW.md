# Ежедневное сопровождение сезона

## Когда запускать

Каждый день в 21:45 Asia/Krasnoyarsk. Рабочее окно сводки — от текущего сброса до следующего четверга 21:30.

- **Четверг:** создать первичную сводку нового сезона после сброса. Заполнить только подтверждённые сведения; неизвестные решения, карты, машины и коды оставить пустыми с явной пометкой `TODO`.
- **Пятница–среда:** сначала найти все `TODO`, пустые поля, `accessIssues` и неопределённости, затем искать только недостающие или изменившиеся данные текущей недели.
- Если свежих подтверждений нет, не менять файлы только ради новой временной метки и не создавать пустой Git-коммит.

## Что собрать

1. Подтвердить название Series, сезон, даты, общее число очков и сезонные награды.
2. Переписать **все** активности в той же последовательности, в которой они перечислены в официальной Festival Playlist и показаны в игровой ленте: Weekly → семь Daily → Photo Challenge → Treasure Hunt/Collectibles → Championships → PR Stunts → The Trial → Horizon Play → Monthly Rivals. Отсутствующий тип активности отметить явно, но не придумывать для него карточку.
3. Для каждой активности записать условие, награду, пошаговую практическую подсказку и известные ловушки засчитывания. Не объединять несколько заданий в общий пункт, если в игре у них отдельные карточки.
4. В каждой активности, где игрок может выбрать автомобиль, указать основной автомобиль, класс/PI, автора и 9-значный share code. Если тюнинг не нужен, машина выдаётся игрой или выбор автомобиля не влияет на результат, написать это явно вместо пустого поля.
5. Для The Trial, чемпионатов и PR Stunts по возможности дать основной и запасной варианты. Для Daily, фото, сундука и Horizon Play разрешено рекомендовать одну практичную машину либо явно указать, что достаточно стока/любой машины.
6. Найти точные решения Treasure Hunt, Photo Challenge и Collectibles. Для местоположений дать словесный ориентир и прямую ссылку на карту/скриншот.
7. Проверить комментарии на ошибки регистрации, неверные фильтры, мокрую/снежную трассу, баги и необходимость повторно применить тюнинг.
8. Проверить полноту: число отдельных карточек в отчёте должно совпадать с числом активностей текущей недели, а сумма очков по всем карточкам — с общим сезонным максимумом.
9. В четверг создать новый файл в `seasons/` и обновить `CURRENT_WEEK.md`; при каждом содержательном дополнении обновить сезонный файл, `reports/SOURCE_NOTES.md`, `reports/artifact.json` и `reports/current-week.html`.
10. После успешной проверки отправить изменённые файлы в ветку `daily-season` публичного GitHub-репозитория без force-push.

## Правила качества

- Время сброса подтверждать минимум двумя источниками, один из них — официальный Forza.
- Ограничения и награды брать с официальной страницы/графики; Reddit использовать для маршрутов, тюнингов и обнаруженных багов.
- Местоположение считать подтверждённым, если есть карта/скриншот или два независимых текстовых описания.
- Не придумывать share code. Каждый код должен находиться в доступном посте текущей недели.
- Если сведения появились только в одном свежем посте, ставить пометку `предварительно`.
- Если точного решения ещё нет, написать это прямо и запланировать повторную проверку, а не копировать прошлую неделю.
- Не переносить тюнинг или share code из прошлого сезона без свежего подтверждения текущей недели.
- Ссылки должны вести на конкретный материал, не на поисковую выдачу.

## Формат итоговой сводки

- Не строить отчёт вокруг порогов 20/40 очков и не предлагать один «правильный» маршрут вместо полного списка.
- В начале дать короткий статус сезона, дедлайн, награды и число карточек/очков.
- Затем показать полный индекс и подробные карточки в игровом порядке.
- Для каждой карточки использовать одинаковые поля: **условие**, **награда**, **как выполнить**, **автомобиль**, **тюнинг**, **статус проверки**.
- Отдельно показать диаграмму распределения всех сезонных очков по типам активностей; диаграмма не должна подменять список заданий.
- В конце собрать общие ловушки и оставшиеся неопределённости, не дублируя инструкции из карточек.
