# Ежедневное сопровождение сезона

## Когда запускать

Каждый день в 21:45 Asia/Krasnoyarsk. Рабочее окно сводки — от текущего сброса до следующего четверга 21:30.

- **Четверг:** создать первичную сводку нового сезона после сброса. Заполнить только подтверждённые сведения; неизвестные решения, карты, машины и коды оставить пустыми с явной пометкой `TODO`.
- **Пятница–среда:** сначала найти все `TODO`, пустые поля, `accessIssues` и неопределённости, затем искать только недостающие или изменившиеся данные текущей недели.
- Если свежих подтверждений нет, не менять файлы только ради новой временной метки и не создавать пустой Git-коммит.

## Что собрать

1. Подтвердить название Series, сезон, даты, общее число доступных очков и награды за 20/40 очков.
2. Переписать все активности с ограничениями по классу и типу автомобиля.
3. Найти точные решения Treasure Hunt, Photo Challenge и Collectibles. Для местоположений дать словесный ориентир и прямую ссылку на карту/скриншот.
4. Для The Trial, чемпионатов и PR Stunts подобрать по одной основной машине и одному запасному варианту. Указать автора и share code.
5. Проверить комментарии на ошибки регистрации, неверные фильтры, мокрую/снежную трассу, баги и необходимость повторно применить тюнинг.
6. Составить два маршрута: быстрые 20 очков и эффективные 40 очков.
7. В четверг создать новый файл в `seasons/` и обновить `CURRENT_WEEK.md`; при каждом содержательном дополнении обновить сезонный файл, `reports/SOURCE_NOTES.md`, `reports/artifact.json` и `reports/current-week.html`.
8. После успешной проверки отправить изменённые файлы в ветку `daily-season` публичного GitHub-репозитория без force-push.

## Правила качества

- Время сброса подтверждать минимум двумя источниками, один из них — официальный Forza.
- Ограничения и награды брать с официальной страницы/графики; Reddit использовать для маршрутов, тюнингов и обнаруженных багов.
- Местоположение считать подтверждённым, если есть карта/скриншот или два независимых текстовых описания.
- Не придумывать share code. Каждый код должен находиться в доступном посте текущей недели.
- Если сведения появились только в одном свежем посте, ставить пометку `предварительно`.
- Если точного решения ещё нет, написать это прямо и запланировать повторную проверку, а не копировать прошлую неделю.
- Не переносить тюнинг или share code из прошлого сезона без свежего подтверждения текущей недели.
- Ссылки должны вести на конкретный материал, не на поисковую выдачу.

## Оптимизация маршрута

Сначала считать очки, затем группировать действия по автомобилю и району карты. По возможности:

- совместить Weekly Challenge и фото;
- пройти все PR Stunts одной A700-машиной;
- закрыть Monthly Rivals чистым медленным кругом;
- запускать The Trial раньше одиночных чемпионатов, если нужна быстрая цель 40 очков;
- учитывать, что Stunt Party начинается в начале каждого часа и имеет 10-минутное окно регистрации.
