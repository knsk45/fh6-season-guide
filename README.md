# Forza Horizon 6 — еженедельные подсказки

Проект хранит практические русскоязычные сводки по Festival Playlist: где искать сундуки и коллекционные предметы, какие машины и тюнинги брать, и в каком порядке закрывать задания с минимальными затратами времени.

## Ритм обновления

Сезон FH6 меняется каждый четверг в 14:30 UTC, то есть в 21:30 по Красноярску (UTC+7). Автоматизация запускается ежедневно в 21:45:

- в четверг создаёт первичную сводку нового сезона из уже подтверждённых данных, оставляя неизвестные поля пустыми с `TODO`;
- с пятницы по среду повторно проверяет только пробелы и свежие исправления — сундук, фото, коллекционные предметы, машины, авторов и 9-значные share codes;
- при отсутствии новых подтверждений не переписывает отчёт и не создаёт пустой коммит.

Публичные обновления отправляются в ветку `daily-season`. Основной ежедневно обновляемый файл — [`reports/current-week.html`](reports/current-week.html); краткая Markdown-навигация находится в [`CURRENT_WEEK.md`](CURRENT_WEEK.md). Персональное состояние игрового автопилота и журналы прохождения остаются только локально.

## Структура

```text
CURRENT_WEEK.md             — ссылка на актуальную сводку
seasons/YYYY-MM-DD-*.md     — архив недель
reports/current-week.html   — автономный HTML-отчёт текущей недели
reports/artifact.json       — исходные данные HTML-отчёта
docs/WORKFLOW.md            — порядок еженедельного исследования
docs/SOURCES.md             — приоритет источников и верификация
docs/WEEKLY_TEMPLATE.md     — обязательная структура сводки
```

Коды тюнинга из сообщества всегда помечаются как внешние рекомендации. Автоматизация не должна выдавать их за лично протестированные, если проверки в игре не было.
