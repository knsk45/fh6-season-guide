# Forza Horizon 6 — еженедельные подсказки

Проект хранит полные практические русскоязычные сводки Festival Playlist: все активности перечисляются в игровом порядке, каждая получает собственную инструкцию, а при выборе автомобиля указываются рекомендуемые машина и тюнинг.

## Ритм обновления

Сезон FH6 меняется каждый четверг в 14:30 UTC, то есть в 21:30 по Красноярску (UTC+7). Автоматизация запускается ежедневно в 06:00 по Красноярску. Первый запуск после смены сезона происходит в пятницу утром, через 8 часов 30 минут после сброса:

- в пятницу создаёт первичную сводку всех карточек нового сезона в порядке Festival Playlist, оставляя ещё неизвестные поля пустыми с `TODO`;
- в остальные дни повторно проверяет пробелы и свежие исправления — условия, способы прохождения, сундук, фото, коллекционные предметы, машины и 9-значные share codes;
- при отсутствии новых подтверждений не переписывает отчёт и не создаёт пустой коммит.

Количество карточек не зафиксировано навсегда: оно берётся из подтверждённой Playlist нового сезона. Старое состояние автоматически сохраняется в `data/history/`.

Публичные обновления отправляются в ветку `daily-season`. Основной ежедневно обновляемый файл — [`reports/current-week.html`](reports/current-week.html); краткая Markdown-навигация находится в [`CURRENT_WEEK.md`](CURRENT_WEEK.md). Персональное состояние игрового автопилота и журналы прохождения остаются только локально.

## Структура

```text
CURRENT_WEEK.md             — ссылка на актуальную сводку
seasons/YYYY-MM-DD-*.md     — архив недель
data/current-season.json    — единственный источник текущих карточек и пропусков
data/project.json           — постоянные настройки проекта, включая поддержку и статистику посещений
data/history/               — архив машинных состояний прошлых сезонов
reports/current-week.html   — лёгкий публичный HTML-отчёт текущей недели
reports/artifact.json       — исходные данные HTML-отчёта
AGENTS.md                   — обязательные проектные инструкции Codex
.agents/skills/             — repo-навык обновления сезона
automation/validate_season.ps1 — блокирующая проверка структуры
docs/WORKFLOW.md            — порядок еженедельного исследования
docs/SOURCES.md             — приоритет источников и верификация
docs/WEEKLY_TEMPLATE.md     — обязательная структура сводки
```

Коды тюнинга из сообщества всегда помечаются как внешние рекомендации. Автоматизация не должна выдавать их за лично протестированные, если проверки в игре не было.
