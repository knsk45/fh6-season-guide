# Автоматизация сезонных активностей FH6

Этот каталог — рабочая точка входа для безопасного прохождения Festival Playlist встроенным автопилотом. Перед каждым новым запуском сначала прочитать актуальную сезонную сводку из `seasons/`, затем `current_run.json` и последний журнал из `runs/`.

## Границы безопасного пакета

- Только одиночные и офлайн-активности, которые игра разрешает пройти встроенным автопилотом.
- Не использовать моды, макросы управления машиной, эксплойты, аукцион и сетевые активности.
- Не покупать машины и тюнинги без явной необходимости. Перед применением тюнинга сверять машину, класс и share code с текущей сезонной сводкой.
- Если автопилот технически не справляется с трассой, остановиться и передать этап пользователю.

## Обязательный порядок перед гонкой

1. Проанализировать Festival Playlist и отметить уже закрытые активности.
2. Выбрать нужный этап и рекомендованную машину/тюнинг из текущей сводки.
3. В свободной езде открыть ANNA клавишей `C`.
4. Убедиться по экрану, что написано **«Автопилот включён»**. Если выключен — нажать `2` и снова проверить надпись.
5. Только после явной проверки входить в событие и подтверждать машину.
6. На стартовом кадре гонки ещё раз проверить индикатор **«Автопилот включён»** в левом нижнем углу.

## Восстановление, если автопилот слетел

Порядок строгий:

1. Открыть ANNA клавишей `C`.
2. Включить автопилот клавишей `2`.
3. Убедиться по экрану, что появилась надпись **«Автопилот включён»**.
4. Открыть паузу и выбрать **«Начать заезд заново»**.

Нельзя сначала перезапускать гонку, а потом включать автопилот.

## Навигация по текущему сезонному чемпионату

Для чемпионата «Белые снега — это не беда»:

1. Пауза → Festival Playlist.
2. Из обзора весны пять раз `Right` — сетка активностей.
3. Верхний левый тайл — завершённый чемпионат «Замкнутый круг»; `Down` — «Белые снега — это не беда».
4. `Enter` открывает карту трёх этапов.
5. Оставшийся третий этап — **«Автокросс по нагорью Сони»**.
6. На карточке этапа `X` → быстрое перемещение → `Enter`.
7. После загрузки дождаться текста **«Автокросс по нагорью Сони»** и **«Продолжить чемпионат»**.
8. `Enter` → **«Продолжить заезд»** → `Enter` → текущий Range Rover → `Enter`.

## Технические заметки для будущих запусков

- Forza работает в полноэкранном режиме 1920×1080. Перед действием активировать единственное окно с заголовком `Forza Horizon 6`.
- Если прямой захват окна показывает Codex поверх игры, активировать Forza и делать контрольный снимок всего экрана. Для снимка 1920×1080 координаты клика совпадают с координатами изображения; не применять старый коэффициент 1,5.
- После каждого значимого перехода делать контрольный кадр и читать название события, выбранную машину, класс, статус автопилота и доступную кнопку.
- Быстрое перемещение подтверждать только если диалог не показывает стоимость.
- Не считать чемпионат закрытым по факту запуска последней гонки. После финиша проверить итоговую таблицу, награду и изменение очков Festival Playlist.

## Что записывать после каждого заезда

- дата и время;
- событие и трасса;
- машина, класс, share code;
- кто прошёл: автопилот или пользователь;
- место, время и очки чемпионата;
- перезапуски и причина;
- состояние автопилота до старта и на первом контрольном кадре;
- итог активности в Festival Playlist.
